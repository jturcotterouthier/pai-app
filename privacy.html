Privacy Policy

PAI — Personal AI Infrastructure · Last updated 7 October 2026

PAI is private, single-user software operated by Jérôme Turcotte-Routhier. It is not offered to the public, has no other users, and collects nothing from anyone else. This policy describes how PAI handles data from the Google Account of its sole user.

Data accessed

  • Google Contacts (auth/contacts) — names, email addresses, phone numbers, postal addresses, and organisations, read and written so the assistant can look up and maintain the user's own address book.
  • Gmail (gmail.readonly) — message metadata and content, read only, so the assistant can summarise and triage the user's own mail. PAI cannot send, delete, or modify mail.

How it is used

Solely to perform tasks the user asks for, on their own data, at the moment they ask. There is no profiling, no advertising, no analytics, and no automated decision-making affecting anyone else.

Storage and retention

Google data is processed on hardware the user owns and is not retained beyond what a task requires. OAuth credentials are stored locally with owner-only file permissions. No Google user data is held in any hosted database or backup operated for PAI.

Sharing

PAI does not sell, rent, trade, or transfer Google user data to any third party. Data is not used to develop, improve, or train generalised artificial intelligence or machine-learning models. PAI's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

The user may revoke PAI's access at any time at myaccount.google.com/permissions. Revocation immediately and permanently ends PAI's ability to read or write the data described above.
